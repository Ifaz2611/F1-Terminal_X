# F1 Terminal X documentation

Welcome to the project documentation for F1 Terminal X.

This repository is organized around a CLI-first and terminal-first approach to Formula 1 telemetry analysis, with a reusable core library for loading sessions, preparing telemetry traces, and generating lap-level insights.

## Project direction

The current v1.5 scope focuses on a reliable core, scriptable CLI, and offline-friendly workflow. Optional desktop, web, and ML layers remain follow-on work and should only be pursued after user demand and scope approval.
