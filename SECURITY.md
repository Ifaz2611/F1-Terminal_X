# Security policy

We take security seriously and appreciate responsible disclosure.

## Reporting a vulnerability

Please report potential security issues through the repository’s private security advisory flow or by opening a private GitHub issue with the maintainer team.

Please avoid sharing:

- raw FastF1 cache dumps or local user data
- personal files, paths, or machine-specific environment details
- sensitive private tokens or access credentials

## What to include

When reporting a vulnerability, include:

- a clear description of the issue
- reproduction steps or affected behavior
- expected vs actual results
- relevant version and environment information
- any proof of concept that is safe and minimal

## Response expectations

We aim to review and acknowledge reports promptly and will work with the reporter to assess the impact and coordinate a fix when appropriate.
